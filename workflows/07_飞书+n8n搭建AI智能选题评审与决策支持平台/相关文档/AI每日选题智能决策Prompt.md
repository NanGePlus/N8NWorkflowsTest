## 任务
你会收到一个 JSON 数组,每个对象代表一条待分配的选题，你需要将每日选题智能分配到以下三个执行池:
1. **头版候选池** - 2小时内响应的重大选题
2. **快讯池** - 当日完成的时效性选题
3. **深度稿池** - 本周完成的深度报道选题

## 分配规则(必须严格遵守)

### 核心原则
1. **互斥性原则**: 每条选题只能进入一个池,按优先级分配: **头版 > 快讯 > 深度**
2. **多样性原则**: 同一赛道在各池中的数量受限,避免单一赛道霸榜
3. **新鲜度原则**: 根据"新鲜度"字段得到距今小时数,超过窗口期的选题自动降级
4. **人工优先级**: 若"人工优先级修正"字段 = "手动提升"或"手动降低",优先执行人工决策

### 头版候选池 (2小时内响应)
#### 准入条件 (必须同时满足)
- 最终热度得分 ≥ 75
- 影响力重要性得分 ≥ 18
- 领域相关度得分 ≥ 15
- 新鲜度 ≤ 24 小时
- 排除: 已进入头版的选题

#### 数量限制
- 最多 **3 条**
- 同一赛道最多 **2 条**

#### 优先级排序(按以下因素综合排序)
1. **紧急预警标记** = true 的选题优先
2. **人工优先级修正** = "手动提升" 的选题优先
3. **最终热度得分**高的优先
4. **影响力重要性得分**高的优先
5. **新鲜度**高的优先(距发布时间越短越优先)
6. **执行槽位** = "必做主线" 的优先

### 快讯池 (当日完成)
#### 准入条件 (必须同时满足)
- 时效性热点程度得分 ≥ 18
- 最终热度得分 ≥ 50
- 新鲜度 ≤ 12 小时
- 排除: 已进入头版候选池的选题

#### 数量限制
- 最多 **5 条**
- 同一赛道最多 **3 条**

#### 优先级排序
1. **距发布时间越短**越优先(超新鲜优先)
2. **时效性热点程度得分**高的优先
3. **竞争度** = "低" 的优先(独家信息)
4. **来源类型** = "官方博客" 的优先(一手信息)

### 深度稿池 (本周完成)
#### 准入条件 (必须同时满足)
- 深度新颖性得分 ≥ 18
- 影响力重要性得分 ≥ 15
- 最终热度得分 ≥ 60
- 排除: 已进入头版候选池或快讯池的选题

#### 数量限制
- 最多 **3 条**
- 同一赛道最多 **2 条**

#### 优先级排序
1. **深度新颖性得分**高的优先
2. **影响力重要性得分**高的优先
3. **变现潜力** = "高" 的优先
4. **内容类型** = "技术拆解" 或 "深度报道" 的优先

## 分配原因生成逻辑

为每条选题生成 `allocation_reason` 字段,说明为什么分配到该池:

```
# 示例模板
allocation_reason = "综合分87(必做级) + 影响力22(高) + 超新鲜(5.3h) + 紧急预警"

# 构造规则
原因片段 = 根据"原因片段"字段得到

allocation_reason = " + ".join(原因片段)
```

## 特殊处理规则

### 1. 赛道多样性控制
- 头版池中,若已有 **2 条"大模型/基础模型"**赛道选题,第 3 条"大模型"选题即使分数够高也**不进入头版**
- 优先保证赛道多样性,避免单一话题刷屏
- 若确需突破限制(如 OpenAI + Google 同日发布重大模型),在 `allocation_reason` 中说明理由

### 2. 竞争度应对策略
根据"竞争度"字段,在 `execution_strategy` 或 `competition_strategy` 中给出建议:

| 竞争度 | 策略建议 |
|--------|---------|
| **低** | "竞争度低,抢占首发,快速发布建立权威" |
| **中** | "竞争度中,需做差异化: 技术拆解/性能对比/独家采访" |
| **高** | "竞争度高,全网已刷屏,必须做极致差异化深度,否则建议降级或放弃" |

### 3. 变现潜力嵌入
根据"变现潜力"字段,提供具体变现路径:

| 变现潜力 | 必须包含的内容 |
|---------|---------------|
| **高** | 必须在 `monetization_path` 中给出 **3 种以上**具体路径 |
| **中** | 给出 **1-2 种**变现建议 |
| **低** | 可不提及变现,或仅标注"广告收入为主" |

### 4. 人工优先级强制执行
- 若"人工优先级修正" = **"手动提升"**:
  - rank_score 自动 **+25 分**
  - 在 `allocation_reason` 中标注"人工提升"
  - 优先分配到头版池(即使不完全满足准入条件)

- 若"人工优先级修正" = **"手动降低"**:
  - rank_score 自动 **-25 分**
  - 在 `allocation_reason` 中标注"人工降低"
  - 可直接丢弃

### 5. 紧急预警特殊处理
- 若"紧急预警标记" = **true**:
  - 必须进入**头版池**或**快讯池**
  - 在 `recommendations` 中单独标注紧急事项

### 6. 时间窗口硬限制

| 池类型 | 时间窗口 | 超时处理 |
|--------|---------|---------|
| 头版 | ≤ 24 小时 | 超过24h但 < 48h,可降级到深度池 |
| 快讯 | ≤ 12 小时 | 超过12h,不得进入快讯池 |
| 深度 | 无限制 | 允许非时效性内容 |
